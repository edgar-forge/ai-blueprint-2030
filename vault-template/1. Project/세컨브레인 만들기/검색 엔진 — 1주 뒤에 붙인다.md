# 검색 엔진 — 1주 뒤에 붙인다

**언제** — 세팅하고 한 일주일 뒤, 일간 노트가 쌓이기 시작했을 때. 세팅하는 날에는 깔지 않는다.

「나중에 너희들이 이게 쌓이고 한 일주일 뒤에 정도 하면 되는 거고」 (성원, 2026-10-12)

---

## 왜 필요한가 — 컴퓨터가 내 노트를 잘 쓰려고

「결국에는 컴퓨터가 이거를 잘 쓰기 위해서 이게 필요한 것이다」 (성원, 2026-10-12)

검색 엔진이 없을 때 Claude가 내 볼트에서 노트를 찾는 방법은 셋이다.

1. 폴더 목록을 본다.
2. 낱말로 훑는다. 찾는 말이 글자 그대로 들어 있는 파일만 걸린다.
3. 걸린 파일을 하나씩 열어 읽는다.

노트가 몇십 장일 때는 이걸로 충분하다. 노트가 쌓이면 두 가지가 막힌다.

- **다른 말로 쓴 노트를 놓친다.** "불안"을 찾는데 내가 "두려움을 다루는 법"이라고 적어 뒀다면 낱말로는 안 걸린다.
- **느리고 무거워진다.** 여러 번 훑고 많이 열어야 해서, 한 번 물을 때마다 시간과 대화 한도를 많이 쓴다.

검색 엔진은 노트를 미리 전부 읽어서, 노트마다 무슨 뜻인지로 정리한 색인을 만들어 둔다. 도서관 사서가 책마다 카드를 꽂아 두는 것과 같다. 그래서 Claude가 이 주제의 노트가 어디 있는지 찾으면, 뜻이 가까운 노트 다섯 장을 경로와 앞부분 글과 함께 바로 받는다. 볼트 전체를 싹 훑지 않아도 어디에 무엇이 있는지 안다.

---

## 무엇인가

부품은 셋이다.

- **KURE-v1** — 문장을 숫자 좌표로 바꾸는 한국어 모델이다. 고려대 연구실이 공개했다. 뜻이 가까운 문장끼리 좌표도 가깝게 놓인다.
- **LanceDB** — 그 좌표를 담아 두고 가까운 것을 빨리 꺼내는 창고다. 따로 서버를 띄우지 않고 내 컴퓨터 안의 파일로 돈다.
- **MCP 서버** — Claude Code가 이 검색기를 도구로 부르게 잇는 연결부다. Claude가 받는 도구는 둘, 뜻으로 찾기와 노트 하나 열기다. 고치거나 지우는 기능은 없다. 자세한 것은 `3. Resource/세팅/MCP 서버.md`.

모델을 처음 한 번 내려받은 뒤로는 전부 내 컴퓨터 안에서 돈다. 노트가 인터넷으로 나가지 않는다.

---

## 어떻게 쓰나

깔고 나면 따로 부를 일이 없다. 평소처럼 Claude에게 묻는다.

- "지난주에 불안에 대해 쓴 노트 찾아 줘"
- "이 글이랑 이어지는 내 예전 노트 있어?"
- "돈에 대해 내가 쓴 생각들 모아 줘"

Claude가 알아서 검색 엔진으로 찾고, 찾은 노트를 열어 읽는다. 색인은 VS Code로 볼트를 열 때 한 번, 바뀐 노트만 새로 읽어 고친다.

---

## 성원은 이렇게 쓴다

- Claude가 성원의 글을 정리하거나 새 글을 쓸 때, 성원이 예전에 쓴 노트를 뜻으로 찾는 데 쓴다. 10월에는 소개 글을 쓰면서 사람들에게 세컨브레인을 알려줬는데 이해를 못했다는 이야기를 뜻으로 찾아, 옛 일간 노트를 꺼냈다.
- 그래도 대부분은 폴더 안 파일을 직접 연다. 2026-09-12부터 한 달 동안 Claude가 검색 엔진을 부른 것은 120번 남짓이고, 파일을 직접 연 것은 4,800번 남짓이다(볼트 밖 파일 포함). 뜻으로 찾아야 할 때만 검색 엔진을 쓴다.
- 검색을 가장 많이 한 달은 8월이다(검색 기록 302건). 9월은 66건, 10월은 12일까지 9건이다.
- 노트끼리 어떻게 이어졌는지는 검색 엔진이 아니라 LLM 위키로 본다 — [[LLM 위키 — 한 달 뒤에 붙인다]].

## 까는 법 — Claude에게 한 줄

```text
https://github.com/edgar-forge/ai-blueprint-2030 의 검색/README.md대로 검색 엔진 붙여 줘. 볼트는 (내 볼트 경로)
```

Claude가 저장소를 받아 `palantir/setup.sh`를 돌린다. 하는 일은 셋이다.

1. 볼트 틀을 한 번 더 훑어 빠진 파일만 채운다. VS Code 색인 작업 파일 `.vscode/tasks.json`이 이때 들어온다.
2. 검색 서버를 `~/obsidian-mcp-server/`에 두고 Claude Code에 등록한다.
3. 첫 색인을 돈다. 모델을 받는 것까지 10~20분 걸린다.

깐 뒤에는 Claude Code를 새로 열어야 검색 도구가 보인다. VS Code로 볼트를 열 때 색인이 저절로 돌게 하려면 `3. Resource/세팅/VS Code.md` 4절을 본다.

---

## 무게 · 주의

- 모델이 약 2GB다. 처음 한 번 받는다.
- Claude Code 창을 하나 열 때마다 검색 서버가 하나 켜진다. 켜져만 있을 때는 메모리를 거의 안 쓰다가, 처음 검색할 때 모델을 메모리에 올리고 그 창을 닫을 때까지 둔다. 메모리가 8GB인 컴퓨터에서 창 여러 개로 검색하면 느려질 수 있다.
- 맥 전용이다. 윈도우에서는 설치 스크립트가 돌지 않는다. 검색 엔진이 없어도 볼트는 그대로 돈다.

설치 설명 한 장 — `3. Resource/세팅/검색 엔진.md`, 저장소 `검색/README.md`.

「」 안은 성원(이 저장소를 만든 사람)이 한 말 그대로다. 나머지 문장은 설명을 위해 정리한 것이다.
