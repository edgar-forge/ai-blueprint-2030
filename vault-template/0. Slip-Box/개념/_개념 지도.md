# 개념 지도 — 내가 쓰는 말

내가 자주 쓰는 말을 두 칸으로 둔다. **단어**는 세상을 보는 이름이고, **행동**은 그 자리에서 내가 하는 것이다. 정리의 기준은 행동이다 — 단어 하나는 어떤 행동으로 이어지는지, 행동 하나는 어떤 단어 위에 서 있는지.

30일의 4주차에 셋을 쓴다 — 단어 하나, 행동 하나는 꼭. 양식은 옆의 두 파일.

## 단어

- [[_양식_단어 — 개념|(예) 기준]] : 무엇이 좋고 나쁜지 가르는 잣대

## 행동

- [[_양식_행동 — 개념|(예) 준비되지 않아도 실행하라]] : 모르는 것은 실행으로만 알 수 있다

## 더하는 법

1. 노트에서 세 번 이상 쓴 말을 찾는다.
2. 단어인지 행동인지 가른다.
3. 양식을 복사해 「이럴 때 걸린다」부터 채운다 — 뜻보다 먼저.
