# 여기는 — 자료 (Resource)

**나중에 쓸 바깥 자료를 둡니다.** 「Resources에서는 관심 주제 참고 자료 나중에 쓸 정보들을 모아보는 거죠」 (3편 08:08)

옷장으로 치면 이렇습니다. 「Resources : 정장, 등산복, 수영복. 지금은 아니지만 언젠가 확실히」 (블로그 21번)

## 무엇을 넣나요

관심 주제 하나에 폴더 하나. 블로그 21번에 옮겨 둔 책의 예는 이렇습니다.

- 습관 형성, 프로젝트 관리 방법론, 노트 작성법
- 커피, 모던 건축, 온라인 마케팅, 숨 수련, 사진
- 마케팅 자산 (코드 스니펫, 템플릿 같은 것들), SEO

성원의 볼트에는 이런 자료 폴더가 있습니다. 책과 영상에서 뽑은 소스, 독서 기록, 도구와 방법론, 조사, 콘텐츠 제작 자료.

세팅 때 들어온 것도 여기 있습니다.

- `성원에게_묻기/` — 궁금한 것마다 답 파일 하나. 파일 이름이 질문입니다.
- `세팅/` — 옵시디언 · VS Code · 검색 엔진 · LLM 위키 · MCP 서버. 성원이 실제로 쓰는 세팅 다섯 장입니다.

## 헷갈릴 때

- **내가 쓴 글인가요, 바깥에서 온 글인가요?** 내가 직접 쓴 메모 원본은 `Reference/`, 매일 쓰는 생각은 `2. Area of Responsibility/My Think/`에 둡니다. 여기는 바깥에서 온 것을 둡니다.
- **지금 하는 일에 바로 쓰나요?** 바로 쓰면 그 프로젝트 폴더로 옮깁니다. 언젠가 쓸 것이면 여기 둡니다.
- **관심이 사라졌으면** `4. Archives/`로 옮깁니다.
- 이미지 · PDF 파일 자체는 `Attachments/`에 모입니다. 여기에는 그것을 다룬 노트를 둡니다.

## AI는 여기서

Claude는 자료를 요약하고 내 노트와 이어 줄 수 있습니다. 요약은 요약일 뿐입니다. 슬립박스로 올리는 노트의 근거는 내가 직접 쓴 글에서만 나옵니다.

PARA가 왜 네 칸인지는 `3. Resource/성원에게_묻기/PARA가 뭐예요.md`.

「」 안은 성원(이 저장소를 만든 사람)이 영상과 블로그에서 한 말 그대로입니다. [3편](https://youtu.be/Pn7M9dvde4A)은 성원의 유튜브 영상, [블로그 21번](https://blog.naver.com/somethinggood230102/224411853137)은 성원의 블로그 글입니다. 나머지 문장은 설명을 위해 정리한 것입니다.
