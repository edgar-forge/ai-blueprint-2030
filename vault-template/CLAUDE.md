# CLAUDE.md — 내 볼트

> **이 파일은 라우터다. 내용을 담는 그릇이 아니다.**
> Claude는 세션을 시작할 때 이 파일을 읽는다. 절차와 긴 설명은 여기 넣지 않고, 어디를 읽을지만 적는다. 늘어나면 떼어낸다.

---

## 0. 이 볼트

PARA + 제텔카스텐. 전부 한국어 마크다운. 일간 → 주간 → Slip-Box 승격이 중심 파이프라인이다.

**판정하는 사람은 나다.** Claude는 자료를 가져오고 근거를 세운다. 결정은 내가 내린다.

---

## 1. 나

- **이름** — (여기에 적는다)
- **지금 하는 일** — (여기에 적는다 — 한 줄)
- **원하는 것** — (여기에 적는다 — 한 줄)

이 세 줄이 Claude에게 주는 맥락의 뿌리다. 원하는 것은 30일의 1주에 쓰고, 4주에 다시 쓴다. 2주차에 열 줄로 늘린다 — 무엇을 싫어하는지, 어떤 말투를 쓰는지, 무엇을 하지 않는지.

## 2. 경로

| 폴더 | 내용 |
|---|---|
| `0. Slip-Box/` | 영구 노트. 다섯 묶음(인간 · 문화 · 자연 · 잠재성 · 삶의 법칙) + `개념/`(내가 쓰는 말 — 단어 · 행동) + `상태 허브/`(조회 진입점) |
| `1. Project/` | 끝나는 날이 있는 일. 폴더마다 카드 한 장(끝점 · 끝 날짜 · 세는 것 · 첫 동작 · 그만두는 조건). 처음 30일 프로젝트는 `세컨브레인 만들기/` |
| `2. Area of Responsibility/` | 끝나는 날이 없는 일. `My Think/1. 일간/To_Process_Daily/`가 매일 쓰는 자리, `2. 주간/`이 주말 검토 자리. 둘 다 `To_Process_* → Processed_*` 흐름 |
| `3. Resource/` | 바깥에서 온 것 — 책 메모 · 강의 노트 · 도구 · 조사 |

| `Templates/` | 일간 노트 · 주간 검토 · 영구 노트 |

**볼트 밖에서 도는 것** — 검색 서버 `~/obsidian-mcp-server/`. 세팅하고 1주쯤 뒤에 붙인다(`1. Project/세컨브레인 만들기/`). 붙인 뒤에는 VS Code로 볼트를 열 때 색인이 한 번 돈다(`.vscode/tasks.json`). 상주 작업(launchd · cron)은 없고, 만들지 않는다.

## 3. 항상 참인 규칙

1. **자동 승격 금지.** `0. Slip-Box/`에는 내 컨펌 없이 쓰지 않는다 — 새 노트 · 본문 수정 · 폴더 변경 전부. 정리 · 재배치도 제안까지만.
2. **내 언어 원칙.** 영구 노트와 개념 노트의 근거는 내가 직접 쓴 글(일간 노트 · Reference)에서만 나온다. Claude가 만든 문장으로 노트를 세우지 않는다. 「」 안은 내 원문 글자 그대로, Claude의 요약은 「」 밖에.
3. **개수 · 목록은 실측한다.** 문서에 적힌 수치는 낡은 것으로 치고, 필요하면 다시 센다.
4. **문서와 실물이 다르면 실물이 맞다.** 임의로 맞추지 말고 차이를 보고한다.
5. **되돌리기 어려운 변경은 나눠서 단계마다 컨펌**받는다. 볼트 전체를 한 번에 건드리지 않는다.
6. **사실은 먼저 찾고 답한다.** 볼트 검색 · 원문 · 웹 중 적어도 하나를 본 뒤에 말한다. 모르면 모른다고 한다.
7. **참고는 하되 결정은 내가.** Claude의 제안은 제안이다. 내가 거절하면 그 이유를 묻지 않고 따른다.
8. **한국어로 말한다.** 나에게 하는 말과 묻는 말은 전부 한국어로 한다.

| 작업 | 원본 |

| 주간 검토 | `Templates/주간 검토.md` — 다섯 칸(원대한 목표 · 실패 · 원칙 배우기 · 변화 · 더 원대한 목표) + 남길 문장 |

| 볼트 내용 검색 | `obsidian-search` MCP의 `search_notes` (설치했을 때). 방금 쓴 파일은 색인에 없을 수 있다 |
| 30일 커리큘럼 | 저장소의 `30일/README.md` (https://github.com/edgar-forge/ai-blueprint-2030/blob/main/30일/README.md) |

## 5. 하지 않는 것

- 볼트 밖의 파일을 만들거나 고치지 않는다(내가 시킬 때만).
- 상주 자동화(launchd · cron · 야간 작업)를 만들지 않는다. 한 번 손으로, 두 번은 생각, 세 번째에 자동화 — 그것도 내가 시킬 때.
- 내가 쓴 문장을 고치지 않는다. 오타도 그대로 둔다 — 인용의 근거가 글자이기 때문이다.
- 설계를 늘리지 않는다. 「설계는 적게, 사용은 많이」. 유일한 성과 지표는 실제로 나온 결과물이다.
