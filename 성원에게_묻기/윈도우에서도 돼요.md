# 윈도우에서도 돼요?

**한 줄** — 성원이 아직 답하지 않은 질문이다 — 오픈채팅에서 물어보면 답이 여기로 돌아온다.

**저장소 실물로 본 것** — 아래는 저장소 파일을 읽고 적은 사실이다. 윈도우 컴퓨터에서 직접 돌려 보지는 않았다.

되는 쪽
- 볼트 틀은 폴더와 .md 글 파일이다. 폴더 · `CLAUDE.md` · 노트는 어느 운영체제에서나 같은 파일이다.
- START.md의 볼트 위치 묻기 · 틀 복사 · `CLAUDE.md` 세 칸 채우기 · 첫 일간 노트에는 맥 전용 명령이 없다. Claude Code가 폴더를 만들고 파일을 복사하는 일이다.
- START.md 3단계의 플러그인 받기(`palantir/install_plugins.sh`)는 bash 스크립트라 윈도우에서는 시험해 보지 않았다. 안 되면 옵시디언에서 직접 깐다(`세팅/옵시디언.md` 3절).

그대로는 안 되는 쪽
- 1주 뒤에 붙이는 검색 엔진의 설치 스크립트 `palantir/setup.sh`는 맥에서 쓰는 bash 스크립트다. 윈도우에서는 그대로 돌지 않는다.
- 볼트를 열 때 도는 색인 `auto_index.sh`도 맥 전용 명령(`stat -f`)을 쓴다. 볼트의 VS Code 작업 파일(`.vscode/tasks.json`)이 이 스크립트를 부른다.
- START.md는 검색 엔진을 깔지 않는다. 검색 엔진이 없어도 볼트는 선다. 검색이 꼭 필요한지는 → `검색 엔진은 꼭 필요해요.md`

**비유 · 예** — 「한 단계 끝내고 다음 단계로 넘어가시면 돼요」 (3편 04:39)
- → 처음 물을 때 윈도우라고 함께 적으면, AI가 그 컴퓨터에 맞는 순서로 한 단계씩 알려 준다.

**나는 이렇게 쓴다(참고만)** — 이 저장소는 맥에서 만들고 맥에서 썼다. 윈도우에서 써 본 이야기는 아직 없다.
