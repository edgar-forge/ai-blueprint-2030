# 돈이 얼마나 들어요?

**한 줄** — 전부 무료입니다. 정보로 돈을 버는 시대가 아니라서, 아는 것은 다 풉니다.

**왜** — 정보는 다 풀어 둡니다. 그래도 정말 어떻게 할지 모르겠으면 성원에게 직접 묻습니다. 묻는 곳은 README에 있습니다.

**무료로 되는 것** — 이 저장소에 있는 것은 전부 무료로 받습니다.
- 볼트 틀 · START.md 세팅 지시 · 답 파일 · 예시 · 가이드 세 권 · 검색 엔진 코드가 다 들어 있습니다. README에도 *유료 전용 기능은 없습니다*라고 적혀 있습니다.
- 검색 엔진은 내 컴퓨터에서 도는 한국어 모델(KURE-v1, 약 2GB)을 한 번 내려받아 씁니다. 쓸 때마다 요금이 붙는 구조가 아닙니다. 세팅하고 1주쯤 뒤에 붙입니다.

**돈이 들 수 있는 곳** — AI 쪽입니다.
- 「근데 지금은요? AI가 발전해서 월 3만원만 내면 솔직하게 까고 말해서 대학생은 Gemini가 1년 동안 공짜입니다 그래서 24시간 함께 상주하는 과외 선생님이 생긴 겁니다」 (4편 14:18)
- → 묻고 배우는 AI(Gemini) 얘기입니다. 세팅에 필요한 Claude Code 요금과 다릅니다.

- 위 금액과 혜택은 4편을 올린 2026년 10월 기준입니다. 요금제는 자주 바뀌니 지금 값은 각 AI의 요금 페이지에서 확인합니다.
- START.md로 하는 자동 세팅은 Claude Code가 있어야 돌아갑니다. Claude Code를 쓸 수 있는 요금제도 Claude 요금 페이지에서 확인합니다.
- Claude Code를 어느 요금제로 쓰는지, 무료로도 되는지는 아직 답하지 않은 질문입니다. 오픈채팅에서 물어보면 답이 여기로 돌아옵니다.
