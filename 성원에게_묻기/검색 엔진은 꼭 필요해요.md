# 검색 엔진은 꼭 필요해요?

**성원이 먼저 물었습니다** — 「MCP 서버가 정말 필요하나?」
- MCP는 클로드 코드에 바깥 도구를 꽂는 연결 방식입니다. 이 저장소의 검색 엔진도 MCP로 꽂힙니다.

**한 줄** — 서버가 없어도 클로드 코드는 볼트 파일을 직접 읽습니다. 서버가 더해 주는 것은 뜻으로 찾기입니다.
- 이 서버는 읽기만 합니다(검색 · 노트 열기 둘뿐, 지우거나 고치는 기능이 없습니다). 풀이 한 장 → [`세팅/MCP 서버.md`](../세팅/MCP%20서버.md)

**왜** — 「단순한 시스템에서 시작을 해서 복잡한 시스템으로 가는 거지 처음부터 복잡한 걸로 가면 안 된다」
- 그리고 무겁습니다. 한국어 검색 모델만 약 2GB이고, 설치에 10~20분이 걸립니다(`검색/README.md`).

**언제** — 세팅하고 한 일주일 뒤, 노트가 쌓이기 시작하면 붙입니다.

**비유 · 예** — 검색 엔진 없이도 AI는 볼트를 뒤져 봅니다
- 「AI가 이것처럼 알아서 제 볼트를 뒤지고 그러니까 제 안에 있는 그런 폴더들을 뒤지고 빈약한 자료 혹은 잘못 인용한 자료들을 찾아주고 논리적인 허점까지 전부 찾아서 보강을 해 주죠」 (4편 05:11)
- 검색 엔진이 붙으면 낱말이 아니라 뜻으로 찾습니다. 찾는 말이 한 글자도 없는 노트도 나옵니다(`검색/README.md`).

**저는 이렇게 씁니다(참고만)**
- 성원은 한국어 검색 엔진을 붙여 씁니다. 전부 자기 컴퓨터 안에서 돌고, 노트가 인터넷으로 나가지 않습니다.
- 이 저장소의 세팅(START.md)은 검색 엔진을 깔지 않습니다. 1주쯤 뒤에 붙이는 순서와 이유는 세팅한 볼트의 `1. Project/세컨브레인 만들기/검색 엔진 — 1주 뒤에 붙인다.md`에 있습니다.
