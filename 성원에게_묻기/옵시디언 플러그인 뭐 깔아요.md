# 옵시디언 플러그인 뭐 깔아요?

**한 줄** — 「여기서 캘린더와 이 6가지를 설치를 해주면 됩니다 일단 이거 까시면 됩니다」 (3편 02:33)
- 영상의 여섯 가운데 지금 실제로 쓰는 것만 다시 추리면 넷입니다. Calendar · Periodic Notes · Smart Typography, 그리고 노션 · 에버노트에서 옮겨 올 때 한 번 쓰는 Importer.
- START로 세팅하면 앞의 셋은 Claude가 받아서 넣어 줍니다. 옵시디언에서 볼트를 처음 열 때 뜨는 창에서 **작성자를 신뢰하고 플러그인 사용하기**를 한 번 누르면 켜집니다.
- 영상의 여섯 가운데 Dataview와 Mousewheel Image Zoom은 뺐습니다. Dataview는 켜져만 있고 하는 일이 없었습니다. 마우스 휠 확대는 옵시디언 1.13부터 기본 기능이 됐습니다. 이미지를 고른 뒤 + · − 키로 크기를 바꾸고 0으로 돌립니다.

**왜 이것만** — 「진짜 쓸모있는 플러그인과 단축키를 진짜 이거를 핵심의 핵심에 정제하면 A4용지 한 장이 나옵니다 이게 전부예요」 (3편 01:32)
- 「이 파레토 법칙은 결국에는 가장 핵심이 되는 20%가 80%의 생산을 낸다는 그런 법칙인데 이 옵시디언도 똑같아요」 (3편 01:18)

**커뮤니티 플러그인 · 필수** (블로그 21번)
- 「Calendar: 사이드바에 달력이 생긴다. 날짜를 클릭하면 그날의 일간 노트로 바로 간다.」
- 「Periodic Notes: Calendar와 세트로 쓴다. 매일 자동으로 일간 노트를 만들어 준다.」

**커뮤니티 플러그인 · 있으면 좋은 것** (블로그 21번)
- 「Smart Typography: 따옴표를 둥근따옴표로, 마침표 셋을 말줄임표로 자동으로 바꿔 준다.」

**커뮤니티 플러그인 · 옮겨 올 때 한 번** (블로그 21번)
- 「Importer: 노션, 에버노트, Apple Notes에서 데이터를 가져올 때 쓴다. 처음 한 번 쓰고 끝이다」

**코어 플러그인** — 「코어 플러그인, 기본 내장이라 켜기만 하면 된다」 (블로그 21번)
- 「Graph view: 노트 간 연결을 그림으로 보여 준다.」
- 「Backlinks: 지금 노트를 가리키는 다른 노트들을 보여 준다.」
- 「Word count: 하단에 글자 수 표시.」

**까는 법** — 「커뮤니티 플러그인은 설정 → 커뮤니티 플러그인 → 탐색에서 검색해서 설치하면 된다.」 (블로그 21번)
- 「사용법은 나중에 차차 알아가시면 되고 솔직히 이거 다 치면 나와요」 (3편 02:33)
