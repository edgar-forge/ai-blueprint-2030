# 클로드 코드 어떻게 설치해요?

**한 줄** — 「그건 바로 AI는 동료라는 겁니다」 (3편 03:34)
- 「이 클로드 코드를 설치하는 방법을 하나하나 물어가면서 설치하시면 됩니다」 (3편 04:54)

**먼저** — 「이제는 클로드 코드를 설치를 해야 됩니다 그리고 이거 솔직하게 검색하면 다 나옵니다」 (3편 02:59)
- Obsidian · Claude Code 설치 링크는 이 저장소 `START.md` 맨 위에 있습니다.

**이렇게 묻습니다** — 제가 실제로 친 말
- 「나한테 클루드 코드를 설치하는 설명해줘」 (3편 03:58)
- 어려우면 「내가 컴퓨터에 대해서 잘 모르거든 그래서 설명해줘 내가 보고 따라 할 수 있게」 (3편 04:13)
- 「한 단계 끝내고 다음 단계로 넘어가시면 돼요」 (3편 04:39)
- → 맥북이라고 말하면 터미널을 여는 방법부터 알려 줍니다.

터미널은 글자로 명령을 쳐서 컴퓨터를 움직이는 창입니다.

**왜 되나요**
- 「이 AI라는 놈의 발전은 그동안 인간이 만들어놓은 지식을 학습하면서 인간처럼 사고하는 능력을 얻었기 때문이에요」 (3편 05:02)
- 「이제는 AI한테 AI 쓰는 법을 물어보면 그것에 대해서 알려주는 시대입니다」 (3편 05:22)

**비유 · 예**
- 「옛날에는 PPT한테 PPT를 사용하는 방법을 물어보는 게 불가능했죠 하지만 이제는 그게 가능하다고요」 (3편 05:22)
- 「심지어 집에서 침대 프레임 그러니까 그런 거대한 쓰레기를 버려야 하는데 이 스티커가 얼마고 이걸 어디서 구매할 수 있는지 그리고 어떻게 버리는지에 대해서도 물어볼 수가 있어요」 (3편 05:43)

**저는 이렇게 씁니다(참고만)** — 「저는 뭐 클루드 코드에 대해서 잘 알지도 못하고 이걸 설치하는 방법도 모릅니다 하지만 그냥 검색해서 그냥 물어보면 돼요」 (3편 03:39)
- → `예시/영구노트/` (AI를 동료로 보는 노트 한 장)

**설치한 다음**
- 이 저장소 폴더에서 `claude`를 실행하고 `세팅해 줘`라고 치면 볼트 세팅이 시작됩니다(`START.md`).
- VS Code 같은 IDE(코드 편집 프로그램)는 없어도 됩니다. 터미널에서 `claude`만 켜면 됩니다. VS Code가 있으면 START가 Claude Code 확장과 한국어 팩을 넣어 주고, 검색 엔진을 붙인 뒤에는 볼트를 열 때 색인도 돌아갑니다(`세팅/VS Code.md`).
- → IDE에서 막히면 이렇게 묻습니다. 「내가 컴퓨터에 대해서 잘 모르거든 그래서 설명해줘 내가 보고 따라 할 수 있게」 (3편 04:13)
- 「자 이 정도 설명했으면 Claude Code 설치까지는 절대로 문제가 되지 않을 겁니다」 (3편 06:29)
