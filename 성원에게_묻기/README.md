# 성원에게_묻기

「잘 몰라도 되는데 그냥 내가 정리한 파일을 AI한테 넣고 물어봐라」
「그렇게 학습하라」
(내 노트(비공개))

이 폴더는 질문 하나에 답 파일 하나다. 답은 성원이 영상 · 블로그 · 노트에 직접 쓴 문장으로 채웠다. 아직 답하지 않은 질문은 답하지 않았다고 적혀 있다.

## 쓰는 법 셋

1. **Claude Code에서 그냥 묻는다.** 이 저장소 폴더에서 `claude`를 켜고 「PARA가 뭐예요?」처럼 묻는다. Claude Code는 폴더를 열면 `CLAUDE.md`부터 읽고, 이 폴더의 답 파일로 답한다.
2. **웹 AI에 묶음 파일 하나를 올린다.** ChatGPT · Gemini · NotebookLM에 저장소 맨 위의 [성원에게_묻기.md](../%EC%84%B1%EC%9B%90%EC%97%90%EA%B2%8C_%EB%AC%BB%EA%B8%B0.md)를 올리고 묻는다. 열일곱 답을 이어 붙인 파일이다.
3. **정말 모르겠으면 오픈채팅.** 「정말 모르겠고 자료를 그러겠으면 나한테 물어봐라.」 (내 노트(비공개)) · 오픈채팅 링크는 곧 단다.

같은 질문이 두 번 오면 답 파일이 하나 는다.
