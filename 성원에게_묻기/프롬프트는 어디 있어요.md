# 프롬프트는 어디 있어요?

**한 줄** — 「이 Git Hub 링크를 그냥 AI한테 넣어버린 다음에 내가 이렇게 만들고 싶은데 어떻게 하는지만 설명해달라고 이야기를 한다면 그 내용들이 알아서 된다라고 설명을 해드렸죠」 (3편 18:03)

**받으면 치는 말** — 따로 외울 프롬프트는 없습니다. 저장소를 받아 Claude Code로 열고 아래 한 줄을 칩니다.

```
START.md를 읽고 그대로 해 줘
```

- 받는 순서는 `README.md`의 *첫 동작* 세 줄입니다. 초록 Code 버튼으로 받고, 그 폴더에서 `claude`를 실행하고, 위 한 줄을 칩니다.
- `세팅해 줘`라고만 쳐도 됩니다. 저장소의 `CLAUDE.md`가 Claude를 START.md로 보냅니다.
- Claude에게 주는 지시문은 `START.md` 아래 절반에 그대로 있습니다. 열어 보면 Claude가 무엇을 하는지 순서대로 보입니다.

**왜** — 「이제는 그냥 내가 하고 싶은 일을 그냥 말로만 말하면 AI가 알아서 이것을 판단하고 그것을 달성하기 위해 모델들을 알아서 나누고 진행을 합니다」 (4편 04:24)

**비유 · 예** — 「그 클로드 코드한테 제 GitHub 링크를 주면서 내가 지금 세컨브레인을 만들고 있는데 이 GitHub 링크에 나와 있는 내용을 바탕으로 내 Obsidian 폴더를 그렇게 구성해줘 라고 이야기를 한다면 클로드 코드가 그걸 해줄 겁니다」 (3편 17:07)
- → START.md 한 줄은 이 말을 저장소 안에 미리 적어 둔 것입니다.

**저는 이렇게 씁니다(참고만)** — 「이 영상을 기획할 때 제가 이런식으로 이 콘텐츠에 대한 아이디어를 두서없이 작성을 하고 그 다음에 작성한 것을 클로드한테 던졌습니다」 (4편 04:45)
