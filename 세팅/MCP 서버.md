# MCP 서버

검색 엔진을 붙일지 정하기 전에 나오는 질문입니다. 성원도 같은 것을 물었습니다.

---

## 성원이 물었다

「근데 MTP 서버가 굳이 있어야 돼. 그냥 내 볼트 내부에서 접근하면 되는 거잖아. 약간 그런 삭제랑 그런 위험이 있는 건가 좀 더 그런 것들을 잘 접근하게 해주는 건가?」(10/10)

음성 인식 그대로라 MCP가 MTP로 적혔습니다.

---

## MCP가 무엇인가

MCP는 Claude 같은 AI가 바깥 도구를 부를 수 있게 하는 약속된 연결 방식입니다. AI 쪽 콘센트 규격이라고 보면 됩니다. MCP 서버는 그 콘센트에 꽂는 기기 하나입니다. 이 저장소의 검색 엔진도 obsidian-search라는 이름의 MCP 서버로 Claude Code에 꽂힙니다.

---

## 답

**지우는 위험은 없습니다.** 이 서버는 읽기만 합니다. Claude에게 주는 도구는 뜻으로 찾기(search_notes)와 노트 하나 읽기(get_note) 둘뿐이고, 노트를 지우거나 고치는 기능은 없습니다. 볼트 밖의 파일은 열지 않습니다. 노트를 고치고 지우는 일은 서버가 아니라 Claude Code가 볼트 파일을 직접 다룰 때 생기고, 그래서 볼트의 `CLAUDE.md`에 하지 말 것을 적어 둡니다.

**서버가 없어도 볼트에 접근합니다.** Claude Code는 서버 없이도 볼트 파일을 직접 읽고 찾습니다. 볼트 안에서 바로 접근하면 된다는 말이 맞습니다.

**서버가 더해 주는 것은 뜻으로 찾기입니다.** Claude Code가 혼자 찾을 때는 글자로 찾습니다. 서버를 붙이면 한국어 모델(KURE-v1)로 뜻이 가까운 노트를 찾아서, 찾는 낱말이 한 글자도 없는 노트도 나옵니다. 노트가 수백 장을 넘어 낱말로는 못 찾을 때 붙이면 됩니다.
