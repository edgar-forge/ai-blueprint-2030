# MCP 서버

검색 엔진을 붙이기 전에 한 번은 나오는 질문입니다. 성원도 같은 것을 물었습니다.

---

## 성원이 물었다

「근데 MTP 서버가 굳이 있어야 돼. 그냥 내 볼트 내부에서 접근하면 되는 거잖아. 약간 그런 삭제랑 그런 위험이 있는 건가 좀 더 그런 것들을 잘 접근하게 해주는 건가?」(10/10)

음성 인식 그대로라 MCP가 MTP로 적혔습니다.

---

## MCP가 무엇인가

MCP는 Claude 같은 AI가 바깥 도구를 부를 수 있게 하는 약속된 연결 방식입니다. AI 쪽 콘센트 규격이라고 보면 됩니다. MCP 서버는 그 콘센트에 꽂는 기기 하나입니다. 이 저장소의 검색 엔진도 obsidian-search라는 이름의 MCP 서버로 Claude Code에 꽂힙니다.

---

## 답

**지우는 위험은 없습니다.** 이 서버는 읽기만 합니다. Claude에게 주는 도구는 뜻으로 찾기(search_notes)와 노트 하나 읽기(get_note) 둘뿐이고, 노트를 지우거나 고치는 기능은 없습니다. 볼트 밖의 파일은 열지 않습니다. 노트를 고치고 지우는 일은 서버가 아니라 Claude Code가 볼트 파일을 직접 다룰 때 생기고, 그래서 볼트의 `CLAUDE.md`에 하지 말 것을 적어 둡니다.

**서버가 없어도 볼트에 접근합니다.** Claude Code는 서버 없이도 볼트 파일을 직접 읽고 찾습니다. 볼트 안에서 바로 접근하면 된다는 말이 맞습니다.

**서버가 더해 주는 것은 뜻으로 찾기입니다.** Claude Code가 혼자 찾을 때는 글자로 찾습니다. 서버를 붙이면 한국어 모델(KURE-v1)로 뜻이 가까운 노트를 찾아서, 찾는 낱말이 한 글자도 없는 노트도 나옵니다. 세팅하고 1주쯤 뒤, 노트가 쌓이기 시작하면 붙입니다(아래 결론).

---

## 10/12에 성원이 또 물었다

「그러면 MCP 서버는 이게 읽기 전용이면 결국에는 내 폴더를 그냥 읽으면 되는 거잖아. 지금은 뭐 어떻게 쓰이는 건데?」

「약간 이 읽기 전용은 하지 않으면 이 클로드가 실수해서 전부 다 지울 수 있기 때문에 약간 그런 건가? 그런 거 방지 차원에서 MCP 서버를 떠, 떠 있게 만드는 건가?」

음성 인식 그대로입니다.

**실제로 쓰이나 — 조금 쓰입니다.** 성원의 컴퓨터에서 한 달(2026-09-12~10-12) 대화 기록을 셌습니다. Claude가 검색 서버를 부른 것은 120번 남짓(뜻으로 찾기 103 · 노트 열기 21)이고, 파일을 직접 연 것은 4,800번 남짓입니다(볼트 밖 파일 포함). 노트를 볼 때는 거의 언제나 폴더 안 파일을 직접 엽니다. 서버는 뜻으로 찾아야 할 때만 부릅니다.

**읽기 전용은 지우는 걸 막는 장치가 아닙니다.** 이 서버가 읽기만 하는 것은 하는 일이 찾기라서입니다. Claude Code는 서버와 상관없이 자기 도구(파일 고치기 · 쓰기 · 터미널 명령)로 볼트 파일을 고치고 지울 수 있습니다. 실수를 막는 장치는 따로 있습니다.

- **Claude Code 권한 설정** — 파일을 고치거나 터미널 명령을 돌리기 전에 사람에게 묻습니다. 작업 폴더 안의 읽기는 묻지 않습니다. 하지 말아야 할 동작을 거부 규칙으로 적어 둘 수도 있습니다. 묻지 않고 진행하는 자동 모드로 쓰면, 사람 대신 안전 검사 장치(분류기)가 위험한 동작을 걸러 냅니다.
- **볼트의 `CLAUDE.md` 규칙** — 슬립박스에는 내 컨펌 없이 쓰지 않는다, 되돌리기 어려운 변경은 나눠서 묻는다.
- **되돌릴 기록** — 옵시디언의 파일 복원(코어 플러그인)과, 쓰는 사람이라면 git 기록.

MCP 규격도 같은 말을 합니다. 도구에 붙은 읽기 전용 같은 표시는 믿을 수 있는 서버가 아니면 믿지 말라고 하고, 도구를 부를 때마다 사람이 거절할 수 있어야 한다고 합니다.

**늘 떠 있지 않습니다.** Claude Code 창을 열면 그 창이 검색 서버를 하나 켜고, 창을 닫으면 꺼집니다. 창을 다섯 개 열면 서버도 다섯 개입니다. 켜져만 있을 때는 메모리를 거의 쓰지 않습니다(한 개 4~5MB, 2026-10-12 실측). 처음 검색할 때 한국어 모델을 메모리에 올리고 그 창을 닫을 때까지 둡니다.

## 결론

지금은 안 붙입니다. 세팅하고 1주쯤 뒤, 노트가 쌓이기 시작하면 검색 엔진과 함께 붙습니다. 순서와 이유는 세팅한 볼트의 `1. Project/세컨브레인 만들기/검색 엔진 — 1주 뒤에 붙인다.md`, 설치 설명은 [검색 엔진.md](검색%20엔진.md)에 있습니다.

「」 안은 성원이 한 말 그대로입니다. 나머지 문장은 설명을 위해 정리한 것입니다.
