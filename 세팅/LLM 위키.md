# LLM 위키

볼트 밖에 따로 두는 노트 구조 지도입니다. 깔지 않아도 볼트는 돌아갑니다. 노트가 쌓인 뒤에 만드는 선택 단계입니다.

---

## 무엇인가

노트 본문을 옮겨 담는 것이 아닙니다. 어느 노트가 어느 노트의 부모이고 자식인지, 어느 노트와 링크됐는지를 목록으로 답하는 지도입니다. 도서관 본관(볼트) 옆에 둔 분류 카드 서랍이라고 보면 됩니다.

「LLM Wiki라는 것이 있는데 AI가 내 말에 이해하기 편하도록 만들어주는 위키에요」(3편 18:22)

Claude가 쓰는 지도이지 사람이 읽는 문서가 아닙니다. 노트 본문과 인용은 언제나 볼트의 원래 노트에서 확인합니다.

---

## 성원은 이렇게 쓴다

Claude Code 플러그인 llm-wiki(https://github.com/nvk/llm-wiki)로 씁니다. 슬립박스 노트가 쌓인 뒤에 붙였고, 노트끼리의 연결을 찾을 때 Claude가 이 지도부터 봅니다.

---

## 설치

Claude Code 안에서 두 줄입니다.

```
/plugin marketplace add nvk/llm-wiki
/plugin install wiki@llm-wiki
```

쓰는 법은 위 저장소의 README를 따릅니다.

---

## 언제 만드나

쌓인 게 있어야 만듭니다. 「LLM Wiki를 만들기 위해서는 내가 그 축적된 자료가 있어야 되는 것이고」(3편 18:47)
