# 옵시디언 세팅

옵시디언(Obsidian)은 글자 파일을 폴더째 열어 서로 링크로 엮어 주는 메모 앱입니다. 노트를 쓰고 읽는 곳이 여기입니다.

이 장은 설치부터 플러그인, 기본 동작 설정, 단축키까지 이 저장소의 볼트 틀(`vault-template/`)에 들어 있는 그대로를 적었습니다. START.md대로 Claude Code가 볼트를 만들었다면 설정 파일과 커뮤니티 플러그인 셋이 이미 볼트의 `.obsidian/` 폴더에 들어 있습니다. 남은 손일은 볼트를 처음 열 때 한 번 누르는 것뿐입니다(1절 4번).

윈도우에서는 아래의 Cmd를 Ctrl로 읽으면 됩니다. 버튼 이름은 옵시디언 한국어 화면 기준이고, 괄호 안이 영어 화면의 이름입니다.

---

## 1. 설치

1. https://obsidian.md 에서 내려받아 설치합니다. 맥에 Homebrew가 있으면 START 때 Claude가 대신 깝니다.
2. 화면을 한국어로 둡니다. 옵시디언이 영어로 나오면 언어(Language)를 한국어로 바꿉니다. 처음 화면에서 바꿀 수 있고, 볼트를 연 뒤에는 설정 → 일반 → 언어에서 바꿉니다.
3. **보관함 폴더 열기**(Open folder as vault)를 눌러 볼트 폴더를 고릅니다. 옵시디언은 볼트를 보관함이라고 부릅니다.
4. 처음 한 번 **이 보관함의 작성자를 신뢰하시나요?** 창이 뜹니다. **작성자를 신뢰하고 플러그인 사용하기**(Trust author and enable plugins)를 누릅니다. 볼트 틀에 플러그인이 들어 있어서 묻는 것이고, 이 볼트는 내가 Claude에게 시켜 만든 것이라 믿어도 됩니다. **보관함을 제한 모드로 탐색하기**를 눌렀다면, 설정 → 커뮤니티 플러그인에서 **제한 모드 종료**(Turn on community plugins)를 누르면 같습니다.

## 2. 코어 플러그인

옵시디언에 처음부터 들어 있는 기능입니다. 따로 깔 필요 없이 켜기만 하면 되고, 볼트 틀에서 아래 열여섯 개를 켜 두었습니다. 켜고 끄는 자리는 설정 → 코어 플러그인(Core plugins)입니다.

- **그래프 뷰**(Graph view): 노트를 점, 링크를 선으로 그려 노트끼리의 연결을 지도처럼 보여 줍니다.
- **백링크**(Backlinks): 지금 노트를 가리키는 다른 노트 목록입니다. 이 생각이 어디서 쓰였는지 거꾸로 따라갑니다.
- **단어 개수**(Word count): 화면 아래에 단어 수와 글자 수를 보여 줍니다.
- **나가는 링크**(Outgoing links): 지금 노트가 가리키는 노트 목록입니다. 백링크의 반대 방향입니다.
- **태그 패널**(Tag pane): 노트에 단 태그를 모아 보여 줍니다.
- **개요**(Outline): 노트 안의 제목들을 목차처럼 보여 줍니다. 긴 노트에서 이동할 때 씁니다.
- **명령어 팔레트**(Command palette, Cmd+P): 모든 기능을 이름으로 찾아 실행합니다.
- **빠른 전환기**(Quick switcher, Cmd+O): 노트 이름을 쳐서 바로 엽니다.
- **파일 탐색기**(File explorer): 왼쪽의 폴더 목록입니다.
- **검색**(Search): 볼트 전체에서 글자로 찾습니다.
- **페이지 미리보기**(Page preview): 링크에 마우스를 올리면 그 노트 내용을 미리 보여 줍니다.
- **편집기 상태 보기**(Editor status): 화면 아래에 지금 편집 중인지 읽는 중인지 표시합니다.
- **파일 복원**(File recovery): 노트를 자동으로 찍어 두어서, 실수로 지운 내용을 되살릴 수 있습니다.
- **노트 작성기**(Note composer): 노트 두 개를 합치거나 일부를 떼어 새 노트로 만듭니다.
- **슬래시 명령어**(Slash commands): 글을 쓰다 `/`를 치면 명령 목록이 뜹니다.
- **템플릿**(Templates): 미리 만든 틀 노트를 지금 노트에 찍어 넣습니다. 틀 폴더는 `Templates`로 지정해 두었습니다. 명령어 팔레트(Cmd+P)에서 템플릿 삽입(Templates: Insert template)을 고르면 `Templates/` 안의 일간 노트 · 주간 검토 · 영구 노트 틀이 뜹니다.

## 3. 커뮤니티 플러그인 넷

다른 사람이 만들어 올린 추가 기능입니다. 휴대폰 앱스토어에서 앱을 받는 것과 같습니다.

**START로 세팅했다면 이미 들어 있습니다.** START 3단계에서 `palantir/install_plugins.sh`가 Calendar · Periodic Notes · Smart Typography 본체를 각 플러그인 저장소의 공식 배포 주소에서 받아 `.obsidian/plugins/`에 넣습니다. 틀에 넣어 둔 설정값은 그대로 적용됩니다. 볼트를 처음 열 때 1절 4번의 창에서 **작성자를 신뢰하고 플러그인 사용하기**를 누르면 셋이 켜집니다.

**직접 까는 법.** 받기에 실패했거나 하나를 더 깔 때입니다. 설정(왼쪽 아래 톱니바퀴) → **커뮤니티 플러그인**(Community plugins)으로 갑니다. 제한 모드가 켜져 있으면 **제한 모드 종료**를 누릅니다. **탐색**(Browse)에서 이름으로 찾아 **설치**(Install)를 누르고, 이어서 **활성화**(Enable)를 누릅니다. Importer는 이렇게 깔거나, 저장소 폴더에서 `bash palantir/install_plugins.sh "<볼트 경로>" --with-importer`로 받습니다.

### Calendar

사이드바에 달력을 띄웁니다. 날짜를 누르면 그날의 일간 노트가 열리고, 없으면 만들지 묻습니다.

- 설정은 손대지 않아도 됩니다. 틀에는 새 노트를 만들기 전에 한 번 묻기, 주 시작은 지역 설정 따르기, 달력 옆에 주 번호 표시가 들어 있습니다.

### Periodic Notes

일간 · 주간 · 월간 노트를 정해진 이름과 폴더로 만들어 줍니다. Calendar가 이 플러그인을 불러 쓰니 둘을 같이 깝니다.

- 일간 노트: 켬
  - 형식 `YYYY. MM. DD` (오늘이 2026년 10월 10일이면 `2026. 10. 10.md`)
  - 폴더 `2. Area of Responsibility/My Think/1. 일간/To_Process_Daily`
  - 템플릿 `Templates/일간 노트`
- 주간 노트: 켬. 폴더 `2. Area of Responsibility/My Think/2. 주간/To_Process_Weekly`, 형식은 비워 두어 `2026-W41`처럼 만들어집니다.
- 월간 노트: 켬. 형식 `YYYY. MM`, 폴더 `2. Area of Responsibility/My Think/3. 월간/To_Process_Monthly`. 이 폴더는 처음 월간 노트를 만들 때 생깁니다.

오늘 일간 노트는 Calendar에서 오늘 날짜를 누르거나, 명령어 팔레트(Cmd+P)에 daily를 쳐서 나오는 명령으로 엽니다.

### Smart Typography

글을 칠 때 문장부호를 바꿔 줍니다. `->`를 치면 →가 되고, 마침표 셋은 말줄임표(…)로, 곧은 따옴표는 둥근 따옴표로, 붙여 친 하이픈 둘은 긴 줄표로 바뀝니다. 성원은 `->`를 쳐서 →를 만드는 데 씁니다.

- 설정은 기본값 그대로입니다.

### Importer (옮겨 올 때 한 번)

노션 · 에버노트 · Apple Notes에 있던 글을 옵시디언 파일로 옮겨 오는 도구입니다. 옮겨 올 글이 있을 때 한 번 쓰고 끝입니다. 그래서 볼트 틀에서는 켜 두지 않았습니다.

- 노션이나 에버노트에서 옮겨 올 것이 있으면 위 방법대로 설치하고, 명령어 팔레트(Cmd+P)에 Importer를 쳐서 엽니다. 다 옮긴 뒤에는 꺼도 됩니다.

## 4. 기본 동작 설정 세 줄

설정 → 파일 및 링크(Files and links)에 있는 값입니다. 볼트 틀의 `.obsidian/app.json`에 들어 있습니다.

1. **첨부 파일은 `Attachments`에.** 이미지나 PDF를 노트에 붙이면 이 폴더에 모입니다. (새 첨부 파일을 생성할 위치, Default location for new attachments)
2. **새 노트는 `Reference`에.** 새 노트를 만들면 이 폴더에 생깁니다. 직접 쓴 메모 원본을 먼저 적는 자리입니다. 쓰는 법은 [레퍼런스는 어떻게 써요](../성원에게_묻기/레퍼런스는%20어떻게%20써요.md). (새 노트를 생성하는 위치, Default location for new notes)
3. **파일 이름을 바꾸면 링크도 따라 바뀝니다.** 노트 이름을 고쳐도 그 노트를 가리키던 링크가 끊어지지 않습니다. (내부 링크를 자동 업데이트, Automatically update internal links)

## 5. 단축키 여섯

성원이 직접 정해 쓰는 단축키입니다. 볼트 틀의 `.obsidian/hotkeys.json`에 들어 있어서 볼트를 열면 바로 됩니다. 바꾸려면 설정 → 단축키(Hotkeys).

| 하는 일 | 단축키 |
|---|---|
| 왼쪽 사이드바 열고 닫기 | `Cmd+\` |
| 오른쪽 사이드바 열고 닫기 | `Cmd+Shift+\` |
| 뒤로 (방금 보던 노트로) | `Cmd+[` |
| 앞으로 | `Cmd+]` |
| 형광펜 | `Cmd+Shift+H` |
| 취소선 | `Cmd+Shift+S` |

형광펜은 고른 글자 앞뒤에 등호 두 개를 붙여 노란 바탕을 칠합니다. 다시 읽을 때 눈에 걸려야 하는 곳에 씁니다.

## 6. 뺀 것 둘

영상 3편의 A4 목록에는 있었지만 지금은 쓰지 않아서 뺀 플러그인입니다.

- **Dataview** — 노트를 표처럼 모아 보여 주는 플러그인입니다. 켜져만 있고 하는 일이 없어서 뺐습니다.
- **Mousewheel Image Zoom** — 마우스 휠로 노트 속 이미지를 키우고 줄이는 플러그인입니다. 옵시디언에 같은 기능이 들어와서 뺐습니다. 옵시디언 1.13(2026-07-30)부터 편집 화면에서 이미지를 고른 뒤 **+** 와 **−** 키로 크기를 바꾸고, **0** 으로 원래 크기로 돌립니다. 이미지를 누르면 크게 열어 볼 수도 있습니다. [옵시디언 1.13 변경 기록](https://obsidian.md/changelog/2026-07-30-desktop-v1.13.4/)

## 나는 이렇게 쓴다

이 장의 바탕은 영상 3편에서 A4 한 장으로 정리한 것입니다. 「단축키 다섯 개 플러그인 아홉 개 이거면 됩니다」(3편 00:25). 단축키 다섯은 새 노트(Cmd+N) · 빠르게 열기(Cmd+O) · 명령어 팔레트(Cmd+P) · 굵게(Cmd+B) · 링크(`[[`)이고, 옵시디언에 원래 있는 단축키라 따로 설정할 것이 없습니다. 「단축키는 총 5개만 알면 됩니다 솔직히 4개예요」(3편 01:48). 플러그인은 코어 셋(Graph view · Backlinks · Word count)에 커뮤니티 플러그인을 더한 것인데, 영상 뒤에 지금 실제로 쓰는 것만 다시 추려 커뮤니티 플러그인은 이 장의 넷이 되었습니다. 더 필요해지면 그때 깔면 됩니다. 「그냥 쓰다가 이런 기능 없나? 이런 기능 좀 있으면 좋을 것 같은데 라고 하면 찾아보시고 설치하시면 돼요」(3편 02:33).
